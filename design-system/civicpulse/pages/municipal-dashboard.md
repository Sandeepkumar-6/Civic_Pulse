# Municipal dashboard

- Present operational totals and distributions only from backend analytics.
- Search and category, status, and ward filters must query the server.
- Use a horizontally scrollable semantic table for dense desktop/tablet management data.
- Keep the map, report detail, assignment, and citizen-facing workflow update actions explicit.
- Ward officers see only their configured ward or city; administrators can review all areas.
- Loading, empty, error, success, keyboard, and reduced-motion states are required.
