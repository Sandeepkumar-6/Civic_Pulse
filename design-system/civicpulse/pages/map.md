# Civic Map Page Overrides

## Layout

- Keep filtering controls above the map and results list at every breakpoint.
- Use a two-column map-and-list layout on desktop and a single column on mobile.
- Preserve a useful map height without forcing the surrounding page to overflow.

## Interaction

- Cluster close reports and display the count directly on each cluster marker.
- Keep category and status filters visible, labelled, and independent.
- Treat device location as optional; provide map-centre search after denial.
- Keep the report list usable whenever street tiles are slow or unavailable.

## Feedback and Accessibility

- Provide loading, empty, network, tile, and permission states in plain language.
- Keep report markers keyboard focusable and give cluster markers accessible names.
- Use the established CivicPulse category colours, status badges, and focus styles.
- Honour reduced-motion preferences for list transitions.
