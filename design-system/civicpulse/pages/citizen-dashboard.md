# Citizen dashboard

- Lead with server-derived totals for all, active, resolved, and awaiting-action reports.
- Keep recent reports, status notifications, nearby issues, and full history visually distinct.
- Preserve a clear report action and profile/settings path at every responsive size.
- Use plain Indian English, IST timestamps, municipal wards, and readable civic references.
- Empty, loading, disabled-preference, and API failure states must remain actionable.
- Motion is limited to the initial content reveal and must honour reduced-motion preferences.
